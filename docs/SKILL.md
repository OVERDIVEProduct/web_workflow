# 工作流程介面樣式

依下列規格選用色彩、文字和按鈕變體。實作時優先沿用專案中相符的色彩變數與元件，並依元素的用途套用對應的字級、字重與行高。

## 色彩分工

| 角色         | 色碼                 | 用途                                                          |
| ------------ | -------------------- | ------------------------------------------------------------- |
| 黃色強調色   | `#EDE186`            | 「執行」預設底色、「邀請協作」邊框及預設文字、卡片 hover 邊框 |
| 黃色強調色   | `#DFD16A`、`#E6D33F` | 「執行」hover、active 底色，依序對應                          |
| 黃色強調色   | `#F8EEA8`、`#F5E677` | 「邀請協作」hover、active 底色，依序對應                      |
| 黃色強調文字 | `#CAB935`            | 「邀請協作」hover 與 active 文字                              |
| 灰色輔助色   | `#F5F5F5`            | 畫布、卡片預設邊框、類型標籤底色、側欄 hover 底色             |
| 灰色輔助色   | `#E8E8E9`            | 側欄 active 底色                                              |
| 主要文字色   | `#444445`            | 側欄、卡片、「執行」文字與播放圖示                            |
| 白色底色     | `#FFFFFF`            | 卡片底色與「邀請協作」預設底色                                |

## 字體規格

使用 **Inter**。網頁實作時，Figma 的 12% 字距對應 CSS `letter-spacing: 0.12em`，自動行高對應 `line-height: normal`。

| 用途                       |            字重 |  字級 |    行高 | 字距 |
| -------------------------- | --------------: | ----: | ------: | ---: |
| 側欄「首頁」、按鈕「執行」 |     Regular 400 | 18 px |    自動 |  12% |
| 按鈕「邀請協作」           |      Medium 500 | 18 px |    自動 |  12% |
| 卡片標題                   |     Regular 400 | 18 px |   24 px |   0% |
| 卡片說明                   | Extra Light 200 | 13 px | 19.5 px |   0% |
| 卡片類型標籤（如 TRIGGER） |     Regular 400 | 12 px |   15 px |   0% |

## 按鈕樣式

Figma 變體 `cursor` 對應預設狀態，`hover` 對應游標懸停，`active` 對應按下狀態。

| 按鈕             | 預設底色  | Hover 底色 | Active 底色 | 文字色                                       |
| ---------------- | --------- | ---------- | ----------- | -------------------------------------------- |
| Primary／執行    | `#EDE186` | `#DFD16A`  | `#E6D33F`   | 各狀態皆為 `#444445`                         |
| Invite／邀請協作 | `#FFFFFF` | `#F8EEA8`  | `#F5E677`   | 預設 `#EDE186`，hover 與 active 為 `#CAB935` |

- **Primary／執行**採實心樣式，Figma 樣本尺寸為 116 × 37 px，圓角 8 px。播放圖示為 20 × 20 px、`#444445`，與右側文字相距 12 px。
- **Invite／邀請協作**採外框樣式，Figma 樣本尺寸為 118 × 37 px，圓角 8 px。各狀態皆使用 3 px 的 `#EDE186` 邊框，按鈕內容為文字。
- 樣本尺寸對應現有文案。文案變更時，保留按鈕的圓角、字體與圖文關係，並依內容調整寬度。
